# Liberation fonts (report only)

Embedded by `web/scripts/report-pdf.mjs --style course` in the course submission report
(`docs/report/final_report.pdf`). The dashboard never loads them.

| File | Family | Role in the report |
|---|---|---|
| `LiberationSerif-Regular.ttf` | Liberation Serif (metric-compatible with Times New Roman) | body text |
| `LiberationSerif-Bold.ttf` | Liberation Serif Bold | headings and bold text |
| `LiberationMono-Regular.ttf` | Liberation Mono (metric-compatible with Courier New) | code and Redis keys |

Source: the official release `liberation-fonts-ttf-2.1.5.tar.gz` of https://github.com/liberationfonts/liberation-fonts
