# Traceability matrix: proposal commitments -> build step -> code, tests, proof

**Source of the commitments.** The project proposal (PDF) is not in the repository. The 44 commitments below are
the list this file has carried since Step 1, column "Commitment (proposal)", unchanged in wording and number,
cross-checked against [PROGRESS.md](PROGRESS.md) and the step table in
[planning/playbook_v2.md](planning/playbook_v2.md) (§0.1). Freeze review for `submission-rc1`: 2026-11-19.

**Columns.** *Code*: the modules that implement the commitment. *Tests*: the unit (`tests/unit`), integration
(`tests/integration`, run by hand on `make up-full`) and dashboard (`web/tests`, `web/e2e`) tests that cover it.
*Proof*: the committed result file or the make target that demonstrates it. *Status*: **done**, **partial**
(with what is missing and why) or **dropped** (with the reason). No commitment is dropped.

**Checked in CI.** `scripts/check_traceability.py` checks every backticked file, test, module attribute and make
target in the Code, Tests and Proof columns (`traceability:` line of the `python` job). `data/...` and
`models/...` paths are gitignored outputs of make targets (GENERATED); rows of step S18 are PENDING (row 44 is checked
since S18A, because its Step names S18A and S18B).
